# Parran's Poboys — Marketing Content Repository

Version-controlled marketing copy for **Parran's Poboys** (Metairie & Kenner, Louisiana).

## What's inside

| Folder | What it holds |
|---|---|
| `content/blog/` | Blog posts & news articles (SEO + GEO) |
| `content/emails/` | Newsletter & customer email templates |
| `content/menu-copy/` | Menu item copy, descriptions, conversion copy |
| `content/reviews/` | Review responses & feedback log |
| `assets/` | Images, brand assets, scripts |
| `.github/` | PR template, issue templates, workflow files |

## Workflow (how we ship)

1. **Branch** from `main`: `git checkout -b feat/name-type` (see below)
2. **Write** your change.
3. **Open a Pull Request** (PR) — describe the *why* + *what*, not just the *what*.
4. **Review** — at least one other set of eyes on copy.
5. **Squash-merge** to `main` — never merge messy branch history.
6. **Deploy** — the site builders or CMS pull from `main`.

Branches: `feat/`, `fix/`, `docs/`, `blog/` (new post), `chore/`.

## Conventions

- **Commit messages**: `type(scope): description` (Conventional Commits).
- **PRs**: describe motivation, the change, and any risk.
- **Copy review**: at least one approver on all customer-facing copy.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the full process.
